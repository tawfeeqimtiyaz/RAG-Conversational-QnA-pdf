# Conversational RAG with PDF Uploads and Chat History

A Streamlit app that lets you upload one or more PDFs and ask questions about them in a conversation. The app remembers earlier questions in the session, so follow-up questions like "what about the second one?" are rewritten into standalone questions before retrieval. Answers are generated by Groq (`openai/gpt-oss-120b`) using only the retrieved PDF content.

## Features

- Upload multiple PDFs in the browser (no fixed folder)
- Splits PDFs into chunks (5000 characters, 500 overlap)
- Local embeddings with `all-MiniLM-L6-v2` (no embedding API key needed)
- Vector store built with Chroma for each upload
- History-aware retrieval: follow-up questions are reformulated using chat history
- Per-session chat memory, so you can keep a conversation going
- Answers limited to three sentences, based on retrieved context
- Session ID field to keep separate conversations apart

## How it works

```
Uploaded PDFs
     │
     ▼
PyPDFLoader  ──►  RecursiveCharacterTextSplitter (5000 chars, 500 overlap)
                              │
                              ▼
              HuggingFaceEmbeddings (all-MiniLM-L6-v2)
                              │
                              ▼
                  Chroma vector store (retriever)
                              │
   Chat history + new question
                              │
                              ▼
   Groq (openai/gpt-oss-120b) rewrites the question
   as a standalone question (history-aware retriever)
                              │
                              ▼
              Retrieve matching chunks from Chroma
                              │
                              ▼
   Groq answers using only those chunks, with chat history
                              │
                              ▼
   Answer shown, chat history saved per session ID
```

## Prerequisites

- Python 3.11 or 3.12 (recommended)
- A Groq API key from the [Groq Console](https://console.groq.com/keys)
- Git (for cloning)

## Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/<your-user>/conversational-rag-pdf-groq.git
   cd conversational-rag-pdf-groq
   ```

2. **Create and activate a virtual environment**

   Windows (PowerShell):
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

   macOS / Linux:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install the dependencies**

   ```bash
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

   The first install is large because `sentence-transformers` installs PyTorch and `chromadb` has many dependencies.

## Configuration

The Groq key is entered in the app's text box when it loads, so no `.env` file is required. The key is not saved anywhere.

Optional: if you prefer to store the key locally, create a `.env` file:

```
GROQ_API_KEY=your_groq_api_key_here
```

and use it in `app.py` with `os.getenv("GROQ_API_KEY")`.

## Usage

Run the app from the project folder:

```bash
python -m streamlit run app.py
```

Then open the URL Streamlit prints (usually `http://localhost:8501`).

1. Paste your Groq API key into **Enter your Groq API key**.
2. Upload one or more PDF files with **Choose A PDF file**. Wait for processing to finish.
3. Type your question in **Your question**, and press Enter.
4. Read the answer under **Assistant**. The **Chat History** section shows the conversation so far.
5. To start a fresh conversation, change the **Session ID** to a new value.

The first run downloads the `all-MiniLM-L6-v2` embedding model, which can take a minute.

## Troubleshooting

**`401 Invalid API Key` from Groq**
The key entered in the text box is wrong or revoked. Create a new key at the Groq Console and paste it again. Also confirm `app.py` passes `groq_api_key=api_key` (the variable from the text box), not a literal string.

**`ModuleNotFoundError` for a package you installed**
Streamlit is running under a different Python than the one where you installed packages. Start it with `python -m streamlit run app.py` from the activated venv, and check `python -c "import sys; print(sys.executable)"` shows a path inside `venv`.

**`SyntaxError` or `TypeError` on startup**
Check `app.py` for typos, such as `os.environ(...)` (should be `os.environ[...]`). Re-copy the full file if unsure.

**Answers say "I don't know" for questions about the PDF**
The PDF may be a scanned image with no text layer. Scanned PDFs need OCR before they can be searched.

**Slow responses after each question**
Each question calls the Groq model twice (once to rewrite the question, once to answer). `openai/gpt-oss-120b` is a reasoning model, so this can take several seconds.

**Chat history display looks like raw Python objects**
Replace the debug `st.write(...)` lines with a loop over `session_history.messages`, as shown in the app's code notes.

**Old answers appear after uploading a new PDF**
Each upload creates a new Chroma collection, but chat history is stored per Session ID. Change the Session ID to start a new conversation.

## Security notes

- Never hardcode your Groq key in `app.py`. Enter it at runtime or read it from `.env`.
- Never commit `.env` or any key. Keep it in `.gitignore`.
- The uploaded PDFs are written to `temp.pdf` on disk while processing. Delete the file if it stays after you close the app.

Suggested `.gitignore`:

```
.env
venv/
__pycache__/
temp.pdf
chroma/
.chroma/
.streamlit/secrets.toml
```
